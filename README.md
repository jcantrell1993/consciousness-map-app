# Consciousness Map — Entrainment Player

A single-page, in-browser binaural / isochronic tone player with a session log.
Everything runs locally in the browser; session logs are stored on-device only
(localStorage) and are never uploaded.

- Focus-level, brainwave-band and multi-phase session presets
- Timestamped marker log with field-note export (.md) and JSON backup
- Dark mode for use with the screen blacked out; screen-off playback on Android
- Installable as a home-screen app (PWA)

Use stereo headphones for binaural mode.
